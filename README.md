# Стоп Энурез

Android-приложение предотвращает ночной энурез, распознавая звуки ёрзания перед
мочеиспусканием локальной моделью машинного обучения.

## Обучение модели

Версия 1.0.2 нормализует громкость аудио перед извлечением MFCC-признаков и не
передаёт модели энергетический коэффициент `MFCC[0]`. После обновления нужно
обучить модель заново: модель предыдущей версии несовместима с новым набором из
24 признаков и не запускается.

Для обучения добавляйте в "тишину" громкие звуки, не являющиеся ёрзанием.
