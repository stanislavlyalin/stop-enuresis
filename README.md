# Стоп Энурез

Android-приложение предотвращает ночной энурез, распознавая звуки ёрзания перед
мочеиспусканием локальной моделью машинного обучения.

## Вводный тур

Новые пользователи видят пять экранов знакомства с приложением. Доступны
перелистывание жестом, кнопки "Далее", "Пропустить" и возврат к предыдущей
странице. "Начать знакомство" на последней странице и "Пропустить" завершают
тур и открывают сбор данных, не запуская запись и не запрашивая разрешений.
После завершения тур больше не появляется. Незавершённый тур при новом
холодном запуске начинается сначала; поворот экрана сохраняет текущую страницу.
У пользователей прежних версий, уже открывавших "О программе", тур пропускается.

Иллюстрации `onboarding_*.png` хранятся в `drawable-nodpi` с прозрачным фоном
и мягкими краями. Цвета тура имеют отдельные значения для светлой и тёмной
темы. Фон и карточки рисуются средствами Android, текст отделён от изображений.

## Интерфейс и тема

Основные экраны используют XML-разметки, векторные иконки и палитры Android.
В настройках доступны системная, светлая и тёмная темы. Явный выбор прежней
версии сохраняется; без выбора используется системная тема. Числовые настройки
ограничены допустимыми диапазонами. Будильник сохраняет ночное оформление.

Список записей сгруппирован по дате. Действия "Тишина" и "Ёрзает" размечают
фрагмент, удаление доступно в меню строки. Массовая очистка находится в меню
экрана сбора данных и сохраняет выбор периода.

## Обучение модели

Версия 1.0.3 нормализует громкость аудио и использует 32 признака: отдельные
MFCC без энергетического коэффициента `MFCC[0]`, характеристики ширины и
плоскостности спектра, а также его изменения во времени. Классификатор -
экстремальные деревья. После обновления нужно обучить модель заново: модели
предыдущих версий несовместимы и не запускаются.

Обучение использует всю размеченную выборку без ручной балансировки.
На экране отдельно показаны состояние модели, точность и статистика записей.
Очистка выборки доступна в меню и требует подтверждения.

Для обучения добавляйте в "тишину" громкие звуки, не являющиеся ёрзанием.

Иллюстрации основных экранов `training_model.png` и `usage_sleep.png` имеют
прозрачный фон и мягкие края. Тексты и состояния отображаются средствами Android.
Экран запуска показывает текущую фазу сеанса, время окончания паузы и число
эпизодов; сохранение фрагментов можно переключить до начала сеанса.

## Подтверждение ёрзания

До первого обнаружения приложение проверяет последовательные окна звука по 5 секунд.
Первое обнаружение открывает период подтверждения (по умолчанию 2 минуты), в
котором окна той же длины проверяются каждые 2,5 секунды. Последовательные
положительные окна считаются одним эпизодом. Новый эпизод начинается после
отрицательного окна. По умолчанию будильник включается на третьем отдельном
эпизоде. Если период истёк, счёт сбрасывается и проверка вновь идёт без
перекрытия. Число эпизодов и длительность периода меняются в настройках.

Единый защитный интервал действует после запуска и после выключения будильника.
В настройках доступны 30-180 минут с шагом 30 минут, по умолчанию 60 минут.
При обновлении старые два значения не переносятся. Во время паузы микрофон
отключён, распознавание и сохранение образцов не выполняются. По окончании
паузы прослушивание возобновляется автоматически с пустым буфером.
Выбор результата срабатывания больше не требуется. Остановка отменяет ожидание.
Изменение настройки применяется при следующем начале паузы.
Сеанс не восстанавливается после принудительного завершения или перезагрузки.
При сохранении семплов помеченный файл содержит именно окно, которое увеличило
счётчик эпизодов.

Перекрытие начинается только после первого обнаружения. Если исходная проверка
пропускает первое ёрзание целиком, этот режим его не исправит; перед выпуском
нужно проверить такие случаи на реальных записях.

## Выключение будильника

При разрешённом полноэкранном уведомлении будильник включает экран и открывает
ночной экран поверх блокировки. Потяните малыша вправо до горшка, чтобы
выключить звук. При движении меняются два кадра шага; незавершённый жест
возвращает малыша в начало. Для специальных возможностей и клавиатуры
доступно действие "Выключить будильник". Откладывания нет.
Кнопка выключения в приложении и уведомлении запускает ту же защитную паузу.
Если Android запрещает полноэкранное уведомление, звук можно выключить
через уведомление. Сворачивание экрана само по себе не выключает будильник.

## Исследование акустических признаков

Скрипт `tools/analyze_acoustic_features.py` сравнивает признаки формы сигнала,
спектра и MFCC с `MFCC[0]` исключённым. Он не изменяет записи и разделяет
обучение и проверку по ночам, чтобы соседние фрагменты одной ночи
не завышали качество.

После резервного копирования данных приложения распакованный каталог `samples`
можно передать скрипту так:

```bash
# Рассчитать признаки, сравнить модели и сохранить отчёт с графиком
MPLCONFIGDIR=/tmp/matplotlib-stopenuresis python3 tools/analyze_acoustic_features.py --samples /путь/к/samples --output /tmp/stopenuresis-analysis
```

Нужны пакеты `numpy`, `scipy`, `scikit-learn` и `matplotlib`. В отчёте
отдельно указывается результат на последних пяти неразмеченных записях
будильника: они не включаются в обучение.

## Доступность вкладок

Для обучения нужно минимум два размеченных примера каждого класса. Непроверенные
записи не учитываются. Без достаточной выборки открывается "Сбор данных",
с достаточной выборкой без модели - "Обучение". Рабочая модель открывает "Запуск"
и разрешает его даже без обучающих записей. Недоступные вкладки показаны серым,
нажатие объясняет причину в диалоге. Доступность обновляется после разметки,
очистки, обучения, импорта и возврата в приложение.

## Подписанная релизная сборка

В корне проекта нужен локальный `signing.properties` с полями `storeFile`,
`storePassword`, `keyAlias`, `keyPassword`. Путь к хранилищу ключей задаётся
полем `storeFile`. Файл исключён из Git; значения паролей не добавляйте
в команды, исходники и журналы. Без заполненной конфигурации релизная
сборка завершается ошибкой; отладочная сборка ключа не требует.

```bash
# Собрать APK с релизной подписью
./gradlew :app:assembleRelease
```

Результат находится в `app/build/outputs/apk/release/stop-enuresis-<коммит>.apk`.
