# Стоп Энурез

Android-приложение предотвращает ночной энурез, распознавая звуки ёрзания перед
мочеиспусканием локальной моделью машинного обучения.

## Обучение модели

Версия 1.0.3 нормализует громкость аудио и использует 32 признака: отдельные
MFCC без энергетического коэффициента `MFCC[0]`, характеристики ширины и
плоскостности спектра, а также его изменения во времени. Классификатор -
экстремальные деревья. После обновления нужно обучить модель заново: модели
предыдущих версий несовместимы и не запускаются.

Для обучения добавляйте в "тишину" громкие звуки, не являющиеся ёрзанием.

## Подтверждение ёрзания

До первого обнаружения приложение проверяет последовательные окна звука по 5 секунд.
Первое обнаружение открывает период подтверждения (по умолчанию 2 минуты), в
котором окна той же длины проверяются каждые 2,5 секунды. Последовательные
положительные окна считаются одним эпизодом. Новый эпизод начинается после
отрицательного окна. По умолчанию будильник включается на третьем отдельном
эпизоде. Если период истёк, счёт сбрасывается и проверка вновь идёт без
перекрытия. Число эпизодов и длительность периода меняются в настройках.

Защитный интервал после начала прослушивания и интервал после будильника
продолжают запрещать срабатывания. При сохранении семплов помеченный файл
содержит именно окно, которое увеличило счётчик эпизодов.

Перекрытие начинается только после первого обнаружения. Если исходная проверка
пропускает первое ёрзание целиком, этот режим его не исправит; перед выпуском
нужно проверить такие случаи на реальных записях.

## Исследование акустических признаков

Скрипт `tools/analyze_acoustic_features.py` сравнивает признаки формы сигнала,
спектра и MFCC с `MFCC[0]` исключённым. Он не изменяет записи и разделяет
обучение и проверку по ночам, чтобы соседние фрагменты одной ночи
не завышали качество.

После резервного копирования данных приложения распакованный каталог `samples`
можно передать скрипту так:

```bash
# Рассчитать признаки, сравнить модели и сохранить отчёт с графиком
MPLCONFIGDIR=/tmp/matplotlib-stopenuresis python3 tools/analyze_acoustic_features.py --samples /путь/к/samples --output /tmp/stopenuresis-analysis
```

Нужны пакеты `numpy`, `scipy`, `scikit-learn` и `matplotlib`. В отчёте
отдельно указывается результат на последних пяти неразмеченных записях
будильника: они не включаются в обучение.
