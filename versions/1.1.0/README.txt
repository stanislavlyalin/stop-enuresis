Стоп Энурез 1.1.0 - материалы RuStore

Выбран вариант 1: "Поможем проснуться вовремя" и кремовый фон 01-cream.png.
description.txt - название, слоган, краткое и полное описание.
set-01-cream/01.png ... 06.png - шесть карточек для загрузки по порядку.
overview.jpg - общий обзор, не предназначен для загрузки как скриншот.
release.txt - путь к подписанному APK и проверенные контрольные суммы.

Карточки: запуск, сбор примеров, обучение, ночное прослушивание,
выключение будильника, настройки. Формат PNG RGB, 1440x2560,
каждый файл меньше 3 МБ. Системные панели Android обрезаны;
пропорции снимков приложения сохранены. Интерфейс не перерисован.

Источники и повторная сборка
sources/screenshots - исходные снимки реального интерфейса с эмулятора.
sources/manifest.json - заголовки, подписи и границы обрезки.
sources/layouts - готовые SVG-композиции со встроенными изображениями.
assets/backgrounds/01-cream.png - выбранный фон, созданный imagegen.
Остальные фоны, copy-variants.txt и prompts.json сохранены как варианты выбора.

Для повторной сборки нужны Python 3, Pillow, Inkscape и шрифт DejaVu Sans.
Из корня репозитория:
# Собрать шесть карточек и общий обзор из сохранённых исходников.
python3 versions/1.1.0/tools/build_screenshots.py

Условия съёмки
Использована временная debug-установка на эмуляторе, не телефон пользователя.
Записи синтетические: 24 размеченных примера (12 на класс) и 8 новых.
Модель обучена на этих примерах штатным TrainingRepository. Показанные 100%
характеризуют только демонстрационную выборку, а не качество в реальных условиях;
это обозначено на карточке обучения. График заполнен демонстрационными уровнями.
Состояния ночного прослушивания и будильника выбраны временным сценарием съёмки,
без ожидания реального ночного срабатывания. Сценарий удалён после съёмки.
Исходные снимки сохраняют фактические дату, время и локаль эмулятора.

Рабочий код приложения не изменялся. APK fb47109 содержит ранее проверенную
релизную версию; последующие изменения относятся к материалам публикации.
