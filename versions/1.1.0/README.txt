Правила оформления следующих скриншотов
Размер карточки: 1440x2560, PNG RGB, меньше 3 МБ на файл.
Фон: 01-cream.png, заполнение всей карточки с сохранением пропорций.
Шрифт: DejaVu Sans, обычный и жирный; отдельные файлы шрифта не нужны.
Цвет текста: #4B301A. Координаты и размеры ниже указаны в пикселях.
Название "СТОП ЭНУРЕЗ": x=120, базовая линия y=140, размер 30,
межбуквенный интервал 4.
Заголовок: x=120, базовые линии y=270 и 370, размер 78, жирный.
Подпись: x=120, базовые линии y=480 и 528, размер 34, обычный.

Снимать реальный интерфейс приложения, не перерисовывать его.
Удалять системные панели Android, сохранять пропорции снимка.
Размещать снимок по центру горизонтали, верхний край y=650.
Вписывать в область 920x1760, скруглять углы радиусом 30.
Рамка: #63452B, по 14 с каждой стороны, внешний радиус 42.
Проверять читаемость, отсутствие обрезанного текста и размер файлов.
Демонстрационные данные явно обозначать, особенно точность модели.
В текущих карточках записи и график демонстрационные; точность 100%
относится только к синтетической выборке, а не к реальным условиям.
