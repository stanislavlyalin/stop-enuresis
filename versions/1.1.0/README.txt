Стоп Энурез 1.1.0 - подготовка материалов RuStore

Текущий этап: выбор фона и текста. Итоговые карточки со скриншотами
будут подготовлены после выбора оформления и формулировок.

description.txt - название, предварительный слоган, краткая суть и полное описание.
copy-variants.txt - пять пар слоганов и кратких описаний; * отмечает предпочтение.
prompts.json - точные запросы для встроенного imagegen.

Три фона без текста, интерфейса и телефона:
* assets/backgrounds/01-cream.png - светлый кремовый, предпочтительный.
  Ближе всего к светлой теме приложения; спокойный фон для подробных экранов.
  Для будущего заголовка подойдёт тёмно-коричневый цвет.

  assets/backgrounds/02-night.png - тёмный ночной с золотистыми акцентами.
  Подчёркивает ночной сценарий. Для будущего заголовка подойдёт кремовый цвет.

  assets/backgrounds/03-watercolor.png - тёплая акварельная подложка.
  Более мягкое оформление, созвучное иллюстрациям приветствия.
  Для будущего заголовка подойдёт тёмно-коричневый цвет.

PNG созданы встроенным imagegen. Это варианты подложки, а не готовые
карточки для загрузки в магазин. Оригинальные размеры сохранены.
При сборке карточек фон можно обрезать под итоговое соотношение сторон;
снимки интерфейса следует брать из приложения, без перерисовки генератором.
